## Project

Read [docs/brief.md](docs/brief.md) before changing anything. It holds the agreed requirements. Use the terms defined in [GLOSSARY.md](GLOSSARY.md), and respect the decisions in [docs/adr/](docs/adr/). Above all, follow ADR 0001: no client-side JavaScript, no image files on the page, and no motion.

## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.
